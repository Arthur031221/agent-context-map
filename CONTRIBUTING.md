# Contributing

Thanks for taking a look at agent-context-map.

## Report a behavior difference

Open an issue with the client version, launch directory, target path, relevant repository file names, and the output you expected. Remove private instructions before sharing a fixture.

## Send a change

Keep rulesets tied to published documentation. Include a small fixture for each behavior change and run:

~~~sh
npm test
~~~

Do not include private repository contents, account settings, or session transcripts in an issue or pull request.
